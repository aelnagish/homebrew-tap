# Homebrew tap for Fotohaus

Install [Fotohaus](https://aelnagish.github.io/Fotohaus/), a private photo organizer for the Mac, with Homebrew:

```bash
brew install --cask aelnagish/tap/fotohaus
```

This also adds the `fotohaus-cli` command to your Terminal.

Update with `brew upgrade --cask fotohaus`. Uninstall with `brew uninstall --cask fotohaus`. Add `--zap` to
also remove the library database; your photos are never touched.

Fotohaus needs an Apple silicon Mac with macOS 14 Sonoma or newer.
